SEO FAQ

What happens if the crawl is very slow or large?
The crawler seeds from your XML sitemap and walks internal links, with a page cap per job. If the time or page budget runs out first, the audit continues with the pages already crawled and marks the report partial — you'll see an amber note explaining what was and wasn't measured.
Why are some checks "not measured"?
Indexation and some live-insight checks use paid APIs. When no credits are configured or a provider is unavailable, the check honestly reports "not measured" with a hint instead of guessing a number.
How long does an audit take?
Short: from a couple of minutes for small sites to longer for large ones — the crawl, then analysis, run in waves. You can leave the tab and come back; the job stays open under its link (your browser keeps the job id in the URL).
Why are redirects usually on 0?
A redirect is a server response (301 / 302) pointing a URL elsewhere — healthy when a site links directly to final URLs. The count reflects links that returned a redirect chain during the last check; a 0 means none did, not that redirects are missing.
Can it analyze competitors?
Yes — the Competitors tab crawls each competitor and diffs 8 gap dimensions (keywords, content, backlinks, technical, schema, on-page, UX, SERP features). If a competitor blocks the crawler (e.g. robots.txt), you get a partial report from SE Ranking + SERP data with a clear "blocked" note.

What are redirects and why is the count often 0?
A redirect is a server response (301 = permanent, 302 = temporary) that points your visitors from one URL to another — e.g. parker.com → www.parker.com. This is normal and healthy for a site.
The count below only reflects links that returned a redirect chain during the last check. Most sites link directly to final URLs, so the count is usually 0 — a 0 here simply means no checked link redirected, not that redirects are missing.
To inspect a URL's redirects yourself: curl -I https://example.com/page or open Chrome DevTools → Network and look at any 301/302 rows.

How to use SEO Insights

This tab pulls together everything about how your site is found: which keywords you actually use (extracted from your page URLs, titles and meta descriptions, then cleaned by an LLM), where you rank on Google for them, who links to you, and key on-page signals. Start with Keywords and SERP Rankings to see what to target, then use Backlinks and Competitors to find link and content opportunities.

Keywords
Where do these keywords come from?

Keywords are extracted from your site itself — page URL slugs, titles and meta descriptions — then merged with any keywords you track, and tidied up by an LLM into natural search phrases (e.g. "double ferrule fittings manufacturer"). The SERP Rankings section below checks where you rank for these exact phrases. Click "Suggest Keywords" to refresh with more terms.

How do I read these rankings?

Each row is a keyword your site uses, with your current position on Google: lower numbers are better (1 = top result). "Not in top 100" means the phrase didn't appear in the first 100 organic results. Rankings are a point-in-time snapshot — they change daily. Google Search Console

Set up Google OAuth credentials so any user can connect their own Search Console property. Create a Google Cloud OAuth client (Web application), enable the Search Console API, and add your callback redirect URI to its authorized redirects. These credentials are stored in the app database — end users never see them.

SE Ranking Data API

SE Ranking (api.seranking.com/v1) powers the live SEO insights: domain overview with organic traffic estimates, organic/paid keywords, top organic competitors, and the full backlink profile (referring domains, anchor texts, top pages, domain/page authority with history, and new/lost backlinks). Data is refreshed monthly; 100 credits per domain request. Create an API key at seranking.com/api.

GitHub (Apply Changes)

A personal access token (repo scope) lets the Actions tab push approved changes as a pull request on a repo named after the analyzed domain (e.g. example-com). Without a token, approved changes are applied via the in-repo guide instead. Create a token at github.com/settings/tokens.

Email Reports

SMTP lets the app email the branded PDF report to the address you enter on the Analyze form when an audit finishes, and to you manually from the Report tab. Values are stored in the app database; .env is only a fallback.
